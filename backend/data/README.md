# Географические данные

`city.csv` — внешний справочник городов из открытого проекта
[hflabs/city](https://github.com/hflabs/city). Загрузка: `sh scripts/fetch-cities.sh` из backend.
Источник, условия использования и актуальность данных следует проверять в исходном репозитории.
Файл не подменяется учебным списком и не входит в Git.

Для собственного CSV обязательны столбцы `fias_id`, `city`, `region`, `geo_lat`, `geo_lon`.
Координаты могут отсутствовать: такой город возвращается без центра.
Неизвестный ФИАС-код не создаётся автоматически из пользовательского запроса.
Версия первого импорта задаётся `CITY_CATALOG_VERSION` и сохраняется в таблице `cities`.
На пустой БД сервер импортирует CSV и полигоны одной транзакцией. На следующих запусках
он читает PostgreSQL, не требует CSV и не обращается к DaData для ListCities/GetCity.
Изменение CSV само по себе не обновляет уже загруженную таблицу.
Адресные подсказки DaData обслуживаются отдельно.

Необязательный файл `CITY_CATALOG_BOUNDARIES_PATH` содержит JSON-объект:
ключ — ФИАС-код населённого пункта, значение — координаты MultiPolygon
в порядке `[полигон][кольцо][точка][долгота, широта]`.
Первое кольцо — внешний контур, остальные — отверстия; кольца замкнуты.
Нужно использовать проверенные границы населённых пунктов, а не городских округов.
Город без полигона возвращает `has_boundary=false`; поиск по его территории
возвращает `FailedPrecondition`. Радиус выбирается пользователем явно.

Для демонстрации допустим отдельный CSV с учебными населёнными пунктами;
он должен иметь собственную версию и не выдаваться за полный справочник России.
