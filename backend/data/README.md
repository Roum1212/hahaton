# Географические данные

Работающее приложение получает города и адресные подсказки из DaData через бэкенд.
CSV и таблица `cities` больше не используются для поиска и не заполняются при запуске.
Существующие записи БД сохраняются. `CITY_CATALOG_*` больше не нужны в ENV.

Ранее использовался открытый справочник [hflabs/city](https://github.com/hflabs/city).
Файл `city.csv`, если он остался локально, не является источником данных приложения.

DaData возвращает до 20 подсказок по названию и не предоставляет полную выгрузку
всех городов или проверенные границы. Для поиска мероприятий используется выбранный
пользователем круг. Радиус круга не ограничивает запросы адресных подсказок.
